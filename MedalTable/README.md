## Summary

Given the results of a set of Olympic events (the countries that won gold, silver, and bronze in each), build the final medal table, with countries ranked by their medal counts.

## Parameters

| Name | Type | Description |
|---|---|---|
| `results` | `String[]` | One entry per event, listing the three country codes that won gold, silver, and bronze. |

## Returns

`String[]` — one entry per country that appears in `results`, showing the country code and its gold, silver, and bronze totals, in ranked order.
