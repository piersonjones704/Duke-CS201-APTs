# Duke Coursework

My coursework from Duke University, currently covering **CS 201 (Programming in Java)**.

## What's in this repo

### `Duke-CS201-APTs`

Solutions to **APTs**, short, self-contained programming problems assigned in CS 201. Each one gives a method signature and a problem statement, and the solution is graded against hidden test cases, much like a LeetCode-style exercise.

Every solution is a single Java file, and each has a matching `README` (same name, `.md`) that describes the problem: its parameters, constraints, examples, and what the method must return.

| Topic | Problems |
|---|---|
| **Arrays and strings** | Totality, AccessLevel, Gravity, Starter, CirclesCountry, DNAMaxNucleotide, SimpleWordGame, TxMsg, StringCuts, TrueSpace, Anonymous, MemberCheck, Encryption, SoccerLeagues, Follower, Increasing, Varied |
| **Sorting and frequency counting** | SortedFreqs, SortByFreqs, LengthSort, MedalTable, LetterFreq, BigWord, CounterAttack |
| **Linked lists** | List2Long, ListParity, ListsEqual, ListCount, ListSum, MergeLists, AlphaLength |
